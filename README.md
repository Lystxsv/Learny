# Learny

App web de estudio: Pomodoro con descanso, flashcards con repaso espaciado, método Feynman,
ruleta de temas, planificador de fechas y estadísticas. Todo se guarda en el navegador de cada persona.

## Archivos
- `index.html`, `style.css`, `script.js` → la app completa (no necesita instalación).

## Probarla en tu computador
Abre `index.html` con doble clic.

## Publicarla gratis en GitHub Pages
1. Crea un repositorio público en GitHub y sube los tres archivos.
2. En el repositorio: Settings → Pages → "Deploy from a branch" → rama `main`, carpeta `/ (root)` → Save.
3. En 1 o 2 minutos tu app estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## IA (opcional)
Cada persona puede pegar su propia clave gratuita de Gemini en Ajustes ⚙️
(https://aistudio.google.com/apikey). La clave nunca se sube a GitHub: queda solo en el navegador.
Si Google cambia el nombre del modelo, se puede cambiar en Ajustes sin tocar el código.
